## 1. Что понадобится

- Аккаунт в Telegram (у тебя и у партнёра).
- Компьютер с интернетом — для настройки.
- Для постоянной работы — **сервер (VPS)**. Бот должен работать круглосуточно: он сам
  записывает регулярные платежи и списания кредиток и присылает сводку в начале недели.
  Подойдёт самый дешёвый тариф любого хостинга (1 vCPU, 1–2 ГБ RAM, Ubuntu 22.04/24.04) —
  обычно это несколько долларов в месяц.

> Попробовать бота можно и без сервера — на своём компьютере (вариант А), но пока компьютер
> выключен, бот не отвечает и не присылает сводки.

## 2. Создать бота в @BotFather

1. Открой в Telegram [@BotFather](https://t.me/BotFather) и нажми **Start**.
2. Отправь команду `/newbot`.
3. Введи **имя** бота — оно видно в чате, например: `Наш бюджет`.
4. Введи **username** — уникальное имя латиницей, обязательно заканчивается на `bot`,
   например: `anya_budget_2026_bot`.
5. BotFather пришлёт **токен** — строку вида `123456789:AAH4...`. Это «пароль» от бота:
   сохрани его и никому не показывай. Если токен утёк — `/revoke` в BotFather выдаст новый.
6. (Необязательно) Там же можно поставить аватарку `/setuserpic`, описание `/setdescription`
   и текст «О боте» `/setabouttext`.

Меню команд (`/budget`, `/chart`, `/summary` …) бот пропишет себе сам при первом запуске.

## 3. Узнать свой Telegram ID и ID партнёра

ID нужен, чтобы закрыть бота от посторонних: пользоваться им смогут только перечисленные люди.

- Самый простой способ — написать боту [@userinfobot](https://t.me/userinfobot): он ответит
  числом `Id: 123456789`.
- Или позже, когда твой бот уже запущен, отправь ему команду `/myid`.

Попроси партнёра сделать то же самое. Оба числа понадобятся на шаге 5.

## 4. Скачать код

Бот лежит в папке `budget-bot` репозитория.

**Через git** (на сервере или на компьютере):

```bash
git clone https://github.com/LIS-One/Artie-app.git
cd Artie-app/budget-bot
```

> Пока изменения не влиты в основную ветку, код находится в ветке
> `claude/telegram-budget-tracker-bot-zdfqq8`. Тогда клонируй так:
> `git clone -b claude/telegram-budget-tracker-bot-zdfqq8 https://github.com/LIS-One/Artie-app.git`
>
> Если репозиторий приватный, git попросит логин GitHub и вместо пароля — персональный токен
> (GitHub → Settings → Developer settings → Personal access tokens).

**Без git:** на странице репозитория на GitHub нажми **Code → Download ZIP**, распакуй архив
и открой папку `budget-bot`.

## 5. Заполнить файл настроек .env

В папке `budget-bot` скопируй пример настроек:

```bash
cp .env.example .env        # Linux / macOS
copy .env.example .env      # Windows
```

Открой `.env` в любом текстовом редакторе (на сервере — `nano .env`) и заполни:

```ini
BOT_TOKEN=123456789:AAH4...твой_токен
ALLOWED_USER_IDS=111111111,222222222     # твой ID и ID партнёра через запятую
TIMEZONE=Asia/Jerusalem
SUMMARY_WEEKDAY=sun                      # сводка по воскресеньям (начало недели в Израиле)
SUMMARY_TIME=09:00
```

Остальное можно не трогать. Полный список настроек — в [разделе 12](#12-все-настройки-env).

## 6. Запуск: три варианта

### Вариант А. На своём компьютере — чтобы попробовать

1. Установи **Python 3.11 или новее**:
   - Windows / macOS — с [python.org/downloads](https://www.python.org/downloads/).
     На Windows при установке поставь галочку **«Add python.exe to PATH»**.
   - Linux — `sudo apt install python3 python3-venv`.
2. Открой терминал в папке `budget-bot` и выполни:

   **Windows (PowerShell):**
   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   python -m budget_bot
   ```

   **macOS / Linux:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python -m budget_bot
   ```
3. В терминале появится строка `Запускаю бота…`. Открой своего бота в Telegram и нажми **Start**.
4. Остановить бота — `Ctrl+C` в терминале.

> Не запускай одного и того же бота одновременно на компьютере и на сервере — Telegram отдаёт
> сообщения только одному экземпляру (будет ошибка `Conflict: terminated by other getUpdates request`).

### Вариант Б. На сервере через Docker — рекомендуется

**1. Арендуй сервер.** Любой VPS-провайдер (Hetzner, DigitalOcean, Contabo, Vultr и т.п.):
ОС **Ubuntu 24.04** (или 22.04), самый маленький тариф. После создания провайдер покажет
IP-адрес и пароль root (или предложит добавить SSH-ключ).

**2. Подключись к серверу.** В терминале (на Windows — PowerShell):

```bash
ssh root@IP_СЕРВЕРА
```

**3. Установи Docker** официальным скриптом:

```bash
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh
docker --version && docker compose version   # проверка
```

**4. Скачай код и заполни настройки:**

```bash
apt-get install -y git
git clone https://github.com/LIS-One/Artie-app.git   # см. примечание про ветку в шаге 4
cd Artie-app/budget-bot
cp .env.example .env
nano .env        # вписать BOT_TOKEN и ALLOWED_USER_IDS, сохранить: Ctrl+O, Enter, Ctrl+X
```

**5. Запусти бота:**

```bash
docker compose up -d --build
```

Первая сборка занимает 2–5 минут. Флаг `-d` значит «в фоне»: бот продолжит работать после
закрытия терминала, а благодаря `restart: unless-stopped` — и после перезагрузки сервера.

**6. Проверь логи:**

```bash
docker compose logs -f      # выход из просмотра — Ctrl+C (бот при этом продолжит работать)
```

Должна появиться строка `Запускаю бота. Данные: /app/data, часовой пояс: Asia/Jerusalem`.
Теперь напиши боту `/start` в Telegram.

**Полезные команды** (выполнять в папке `Artie-app/budget-bot`):

| Что сделать | Команда |
|---|---|
| Посмотреть логи | `docker compose logs -f` |
| Перезапустить | `docker compose restart` |
| Остановить | `docker compose down` (данные сохраняются) |
| Обновить до новой версии | `git pull && docker compose up -d --build` |
| Скопировать данные на сервер в папку | `docker compose cp budget-bot:/app/data ./backup-$(date +%F)` |

> Данные бота (Excel-таблицы, резервные копии) лежат в Docker-томе `bot-data` и не пропадают
> при пересборке или обновлении. Удалить их можно только явно: `docker compose down -v`.

> Подойдёт и любой другой хостинг, который умеет запускать Docker-контейнер 24/7 с постоянным
> диском (volume): смонтируй постоянный диск в папку `/app/data` и задай переменные из `.env`
> в настройках хостинга.

### Вариант В. На сервере без Docker (systemd)

```bash
apt-get update && apt-get install -y python3 python3-venv git
useradd --system --create-home budgetbot
cd /opt && git clone https://github.com/LIS-One/Artie-app.git
cd /opt/Artie-app/budget-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env            # BOT_TOKEN, ALLOWED_USER_IDS
chown -R budgetbot:budgetbot /opt/Artie-app/budget-bot
cp deploy/budget-bot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now budget-bot
journalctl -u budget-bot -f                  # логи
```

Данные будут в `/opt/Artie-app/budget-bot/data`. Обновление:
`cd /opt/Artie-app && git pull && systemctl restart budget-bot`.

## 7. Первая настройка бюджета в боте

Открой бота и нажми **Start** — начнётся анкета из пяти блоков. На каждый вопрос можно
нажать кнопку с частым ответом или написать своё число; «⬅️ Назад» возвращает к прошлому вопросу.

1. **🏠 Постоянные платежи** — жильё, коммунальные счета, арнона, подписки
   (можно списком: `Netflix 50, Spotify 20`) и другие ежемесячные списания (ваад байт, страховка, кредит…).
2. **💼 Доход и деньги** — доход в месяц, день зарплаты, сколько сейчас на счету, кредитки:
   день списания и текущая сумма к списанию (можно добавить несколько карт).
3. **🛒 Основные траты** — продукты (в неделю), транспорт, здоровье, одежда.
4. **🎯 Привычки** — хобби, кафе, рестораны, доставка, сигареты, игры, вторая половинка,
   спонтанные покупки, непредвиденные расходы, другие частые траты и свои категории, нюансы.
5. **💰 Цель накоплений** — бот посчитает, сколько остаётся, и предложит сумму.

Дальше бот присылает **анализ** (структура бюджета, наблюдения по привычкам) и **предложенный
бюджет по категориям**. Прямо в этом же окне можно:
- нажать на категорию и написать свою сумму — остальное пересчитается;
- нажать «💰 Цель» и написать, сколько хочешь откладывать, — бот подстроит гибкие категории;
- нажать **✅ Сохранить бюджет**.

После сохранения появится меню внизу экрана и круговая диаграмма бюджета. Всё, что задано в
анкете, потом меняется в **⚙️ Настройках** (или можно пройти анкету заново: `/setup`).

## 8. Подключить партнёра (пара)

У каждого свой бюджет и своя таблица, но вы можете смотреть бюджеты друг друга.

1. Партнёр открывает того же бота (по ссылке `https://t.me/username_твоего_бота`),
   его ID должен быть в `ALLOWED_USER_IDS`.
2. Один из вас: **👫 Пара → 🔗 Пригласить** — бот даст ссылку и код (действуют 7 дней).
   Отправь ссылку партнёру.
3. Партнёр открывает ссылку. Если он новый — сначала пройдёт свою анкету, затем бот предложит
   **✅ Принять** приглашение. (Или: **👫 Пара → 🔑 Ввести код**.)
4. Готово: в **👫 Пара** появятся «Бюджет», «Сводка», «Диаграмма», «Операции» и «Excel партнёра».

Разорвать связь может любой из двоих: **👫 Пара → 💔 Разорвать связь**.

## 9. Как пользоваться каждый день

- **Записать трату** — просто напиши в чат: `45 кофе`, `wolt 89`, `1 200 шуферсаль`.
  Категорию бот подберёт сам (по ключевым словам и по твоим прошлым записям), оплату поставит
  кредиткой по умолчанию. Под записью — кнопки «🏷 Категория», «💳 Оплата», «✏️ Сумма»,
  «💬 Описание», «📅 Дата», «🗑 Отменить». Команда `/undo` отменяет последнюю запись.
- **Задним числом** — если забыл(а) записать вовремя: `вчера 45 кофе`, `позавчера 30 такси`,
  `25.09 120 продукты`, `25 сентября 120 продукты`. Дата пишется в начале (слова «вчера» и
  «позавчера» — где угодно). Будущие даты бот не примет. Дату уже записанной операции меняет
  кнопка «📅 Дата».
- **Доход** — с плюсом: `+12000 зарплата` (задним числом: `вчера +500 кешбэк`), или кнопка **💵 Доход**.
- **📊 Бюджет** — сколько потрачено и осталось по каждой категории, сколько можно тратить в день.
- **🥧 Диаграмма** — круговая диаграмма бюджета («План») и реальных трат («Траты»).
- **📈 Сводка** — последние 7 дней. Автоматически сводка приходит в начале каждой недели
  (по умолчанию в воскресенье в 09:00): сколько потрачено за неделю и с начала месяца,
  сколько осталось, сколько на счету и сколько спишется по картам.
- **🏦 Счёт** — баланс, суммы к списанию по картам, ближайшие платежи. Раз в неделю полезно
  нажать «✏️ Сверить баланс с банком» и вписать реальную сумму из приложения банка.
- **📋 История** — все операции; нажми номер, чтобы исправить или удалить.

Что бот делает сам (каждое утро в `DAILY_JOB_TIME`):
- в день списания записывает постоянные платежи (жильё, счета, подписки…);
- в день списания кредитки переносит накопленную сумму с карты на счёт и пишет, сколько списалось;
- в день зарплаты записывает доход (сумму можно поправить кнопкой).

Уведомления (всё включается и выключается в **⚙️ Настройки → 🔔 Уведомления**):
- **⚠️ Лимиты** — отдельное сообщение, когда категория дошла до 80% лимита («осталось столько-то,
  ≈ столько-то в день») и когда лимит исчерпан. Предупреждение приходит один раз при пересечении
  порога, только за текущий месяц.
- **👀 Партнёру о лимитах** — по желанию те же предупреждения получает партнёр (по умолчанию
  выключено; решает тот, чей бюджет).
- **🌙 Вечернее напоминание** — если за день не записано ни одной траты, бот спросит, всё ли верно
  (по умолчанию в 21:00; время можно выбрать или выключить; под напоминанием есть кнопки
  «✅ Сегодня трат не было» и «🔕 Не напоминать»).
- **📬 Сводка за неделю** — включается/выключается там же.

## 10. Работа с Excel-таблицей

- **📁 Excel** — бот пришлёт твою таблицу. Она открывается в Excel, Google Таблицах, Numbers.
- Листы: **Сводка** (месяц целиком + диаграммы), **Операции**, **Бюджет** (лимиты и ключевые
  слова), **Постоянные**, **Карты**, **По месяцам**, **Анкета**, **Профиль**, **Справка**.
- Можно исправить данные в таблице и **прислать файл обратно в чат**: бот покажет, что нашёл,
  и после подтверждения загрузит. Перед заменой сохраняется резервная копия.
- Правила: не переименовывай листы и заголовки колонок; сумма всегда положительная, тип задаёт
  знак («Расход», «Доход», «Списание карты»); оплата — «Счёт» или название карты.
- Пример таблицы с демо-данными: [`examples/budget_demo.xlsx`](../examples/budget_demo.xlsx).

## 11. Резервные копии и обновление

- Бот каждый день сохраняет копию таблицы каждого пользователя (хранятся последние 30) в
  `data/backups/<ID>/`, а также перед загрузкой Excel и перед повторной анкетой.
- Структура папки `data`:
  - `users/<ID>.xlsx` — таблица пользователя (главное хранилище данных);
  - `registry.json` — кому слать сводки, кто с кем в паре;
  - `conversations.pickle` — незаконченные диалоги (например, анкета на середине);
  - `backups/` — резервные копии.
- Копия всех данных с сервера на компьютер (Docker): на сервере
  `docker compose cp budget-bot:/app/data ./backup-$(date +%F)`, затем с компьютера
  `scp -r root@IP_СЕРВЕРА:Artie-app/budget-bot/backup-* .`
- Автоматическая копия раз в сутки (Docker): `crontab -e` и строка
  `0 4 * * * cd /root/Artie-app/budget-bot && docker compose cp budget-bot:/app/data ./backup-$(date +\%F)`
- Обновление: `git pull`, затем `docker compose up -d --build` (Docker) или
  `systemctl restart budget-bot` (systemd). Данные при обновлении сохраняются.

## 12. Все настройки .env

| Переменная | Что значит | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен от @BotFather — **обязательно** | — |
| `ALLOWED_USER_IDS` | Telegram ID через запятую, кому можно пользоваться ботом. Пусто — всем | пусто |
| `TIMEZONE` | Часовой пояс для сводок и ежедневной обработки | `Asia/Jerusalem` |
| `SUMMARY_WEEKDAY` | День сводки: `sun`, `mon`, `tue`, `wed`, `thu`, `fri`, `sat` | `sun` |
| `SUMMARY_TIME` | Время сводки, ЧЧ:ММ | `09:00` |
| `DAILY_JOB_TIME` | Время записи регулярных платежей, списаний карт и зарплаты | `08:00` |
| `CURRENCY` | Валюта для новых пользователей (потом меняется в настройках) | `₪` |
| `DATA_DIR` | Папка с данными (в Docker всегда `/app/data`) | `data` |
| `LOG_LEVEL` | Подробность логов: `DEBUG`, `INFO`, `WARNING` | `INFO` |

После изменения `.env` перезапусти бота: `docker compose up -d` (Docker) или
`systemctl restart budget-bot` (systemd).

## 13. Частые проблемы

| Симптом | Что сделать |
|---|---|
| Бот не отвечает | Проверь, что он запущен: `docker compose ps` / `systemctl status budget-bot`, и посмотри логи. Проверь `BOT_TOKEN` в `.env`. |
| `Ошибка настройки: Не задан BOT_TOKEN` | Не создан `.env` или в нём пустой токен (шаг 5). |
| `telegram.error.InvalidToken` | Токен скопирован с ошибкой или был отозван — возьми новый в @BotFather. |
| `Conflict: terminated by other getUpdates request` | Бот запущен дважды (например, на компьютере и на сервере). Останови лишний. |
| «⛔ Это личный бот» | ID человека нет в `ALLOWED_USER_IDS`. Бот сам покажет ID — добавь его и перезапусти. |
| Сводка не пришла | Бот должен работать 24/7; проверь `TIMEZONE`, `SUMMARY_WEEKDAY`, `SUMMARY_TIME` и что в ⚙️ Настройки → 🔔 Уведомления сводка включена. |
| Напоминание пришло, хотя трата была | Считаются только операции с сегодняшней датой: если трату записали задним числом («вчера…»), для сегодняшнего дня её нет. |
| «Дата … ещё не наступила» | Записать можно только прошедшую дату. Дата без года, которая наступит позже чем через месяц, считается прошлогодней (например, «25.12» в январе). |
| Баланс на счету не совпадает с банком | 🏦 Счёт → «✏️ Сверить баланс с банком» и впиши реальную сумму. Так же — сумма по карте. |
| Не загружается Excel | Нужен файл `.xlsx` до 5 МБ, листы и заголовки не переименованы. Бот напишет, что именно не так. |
| Трата попала не в ту категорию | Нажми «🏷 Категория» под записью — бот запомнит выбор для таких описаний. Ключевые слова категории можно поправить в ⚙️ Настройки → Категории. |
| После перезапуска бот «догоняет» пропущенные дни | Так и задумано: регулярные платежи и списания за время простоя записываются при запуске. |

Для разработчиков: тесты запускаются так —
`pip install -r requirements-dev.txt && pytest` (в папке `budget-bot`).

## 14. Безопасность и приватность

- Токен бота храни только в `.env`; файл `.env` не попадает в git (он в `.gitignore`).
- Заполни `ALLOWED_USER_IDS`, иначе ботом сможет пользоваться любой, кто его найдёт.
- Все данные хранятся только на твоём сервере, в папке `data`. Партнёр видит твой бюджет
  только после того, как вы оба подтвердили связь, и перестаёт видеть сразу после её разрыва.
- ⚙️ Настройки → «🗑 Удалить мои данные» полностью удаляет таблицу, копии и связь пары.
